# Lumo

<img src="app/src/main/res/mipmap-xxxhdpi/ic_launcher.png" width="120" alt="Lumo 图标" />

安卓漫画阅读器。不做统计上报，干净省心；书架、下载、扩展一应俱全。

Lumo 参考 Mihon 构建，是 Mihon 的一个分支。

</div>

## 功能

- **阅读**：纵向连续 / 横向翻页，亮度、滤镜、灰度可调，支持墨水屏
- **书架**：分类、排序、筛选、批量操作
- **下载**：章节离线缓存，可自定义存储目录
- **扩展**：兼容社区扩展仓库，也能手动装本地扩展包
- **备份**：本地导入导出，支持 WebDAV
